## Mobile products where interface meets intelligence.

I'm a mobile engineer working across product architecture, native capabilities, performance-sensitive interaction and AI integration. I build for iOS and Android, taking products from early technical decisions through release and iteration.

My focus is practical: React Native when shared product velocity matters, native code when the platform demands it, and on-device AI when privacy or latency makes the cloud the wrong place.

### Building with Vespula

I'm part of [Vespula](https://vespula.com.tr/en)'s three-person core team as **Mobile Engineer · Mobile AI**. We design and ship mobile, web, backend and AI-native products with direct engineering ownership from idea to production.
