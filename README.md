## Mobile products, web platforms and applied AI

I'm a software engineer based in **Samsun, Türkiye**, working with [Vespula Software Studio](https://vespula.com.tr/en). I build mobile experiences with React Native, Expo and TypeScript, and applied AI systems with Python.

My work connects product interfaces, APIs and AI components: camera features, subscriptions, real-time communication, on-device computer vision and enterprise knowledge retrieval. I also work on store releases, deployment workflows and production support.

### Building with Vespula

At Vespula, I contribute to both our own products and client projects across mobile, web, backend and AI. The projects below reflect team work; my portfolio describes my contributions in more detail.
